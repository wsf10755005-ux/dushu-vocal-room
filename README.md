# 獨樹一幟練功房 · THE ONE

[開啟歌唱練習室](https://wsf10755005-ux.github.io/dushu-vocal-room/)

![THE ONE 標誌](site/brand-logo.jpg)

以使用者提供的太陽、海浪與海龜原圖作為 App 圖示與品牌，搭配黑底、海浪藍綠和日光黃。照片原圖保留，192／512 px 圖示供手機安裝使用。

提供音高鋼琴捲軸、音分偏差、母音音階、開嗓、音域、節奏、漸強漸弱、數字簡譜圖片辨識、MP3／M4A、LRC 同步歌詞、錄音回放、樂句重練及 MIDI 匯出。分析在裝置內執行，不使用付費 API。

完整網站程式與 OCR 引擎保存在 `site/`；GitHub Actions 負責發布到 GitHub Pages。後續部署使用本儲存庫內的程式，不依賴原始網站。

手機：iPhone 使用 Safari → 分享 → 加入主畫面；Android 使用 Chrome → 選單 → 安裝應用程式。

音檔與練習紀錄保存在各使用者自己的瀏覽器，不會上傳到 GitHub。切換網址前請匯出本機備份，再到新網址還原。
