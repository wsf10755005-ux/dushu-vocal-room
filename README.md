# 獨樹一幟練功房 · GitHub Pages

個人使用的免費公開歌唱練習程式。預計發布於 `https://wsf10755005-ux.github.io/dushu-vocal-room/`，此網址在 Pages 部署完成前不代表已上線。

第一次部署會從已發布版本下載每個靜態資源、比對 SHA-256，將完整網站存到本儲存庫的 `site/`。之後直接使用儲存庫內的程式，不再依賴原始網站。使用者瀏覽、錄音、圖片辨識均在 GitHub Pages 網址與自己的裝置中執行。

GitHub 設定：Settings → Pages → Build and deployment → Source 選 GitHub Actions。

音檔與練習紀錄保存在使用者的瀏覽器，不會上傳到 GitHub。從舊網址搬到新網址前，應先匯出本機備份，並在新網址還原。
